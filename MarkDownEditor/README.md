Markdown Editor

Pequeño editor creado para experimentar y realizar pruebas con Markdown.

El objetivo del proyecto es disponer de una herramienta sencilla donde poder escribir contenido en Markdown, probar diferentes elementos del formato y visualizar su resultado.

El proyecto está desarrollado con HTML, JavaScript y CSS, por lo que puede utilizarse directamente desde un navegador sin necesidad de instalar software adicional.

Solo es necesario abrir el archivo HTML principal para comenzar a utilizar el editor.
